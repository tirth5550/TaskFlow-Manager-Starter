# TaskFlow — Smart Task Manager

TaskFlow is a responsive task-management dashboard built with HTML, CSS and vanilla JavaScript. It demonstrates practical Git, GitLab collaboration and CI/CD workflows.

## Features
- Dashboard statistics and completion progress
- Create, edit and delete tasks
- Pending, In Progress and Completed statuses
- High, Medium and Low priorities
- Search and filter tasks
- Today, Upcoming and Completed views
- Browser localStorage persistence
- Responsive layout for desktop and mobile

## Technologies
HTML5 · CSS3 · JavaScript · Node.js · Git · GitLab CI/CD

## Run locally
No package installation is required. Open `index.html` in a browser, or use the VS Code Live Server extension.

Run validation tests:
```bash
node test.js
```

## GitLab CI/CD
The `.gitlab-ci.yml` file defines a build stage and a test stage. The test stage runs `node test.js`.
